# UnstuckButton
This mod adds a Quick Access Menu bubble that instantly kills you when used, for the purpose of easily getting unstuck.   
This mod needs to be on both the Client and the Server to work properly.  
This mod requires that you also have https://github.com/SmoothieBrain/TabletUILib/ downloaded to work properly.  

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
